# 表情包库

库在 agent 工作目录下的 `stickers/`（即 `~/.dsh-qqbot-akane/workspace/stickers/`），
索引是 `stickers/INDEX.md`。**目录名和索引格式是硬约定**，不要另起目录、不要改名。

发图有两个入口，默认走前者：

| 入口 | 到达顺序 | 什么时候用 |
| --- | --- | --- |
| `present` | 本轮文字**先到**、图**后到** | 默认。想"说完话再甩图"就用它 |
| `akane_send_file` | 图**先于**文字 | 只在用户点名要立刻给图时用 |

本轮没有 `present` 工具可用时，退回 `akane_send_file`。

## 入库

1. 先 `read_image` 真看一遍。**没看过就不要起名**——文件名是唯一可靠的检索面。
2. 命名取**图上的字幕**；没有字幕就用一句语义短语（"翻白眼""地铁老人看手机"这类）。
   不要凭空发挥，也不要保留平台给的哈希名。
3. 查重：`md5sum` 比对，库里已有同内容就不重复入库，只补索引。
4. `cp` 不要 `mv`。`media/` 里的原件由清理器 24 小时后回收，本轮可能还要用。
5. 往 `INDEX.md` 追加一行。

```bash
S="$HOME/.dsh-qqbot-akane/workspace/stickers"
md5sum "$S"/*.jpg "$S"/*.png 2>/dev/null          # 先看有没有同内容
cp "<media 里的绝对路径>" "$S/从来没觉得上班开心过.jpg"
```

**不收库**：带真人头像、聊天截图、昵称、二维码、任何能认出具体人的图。
A 群的图发给 B 群就是泄露，被要求时直说不收，理由可以讲。

## 什么时候该配图

不用等用户开口要图。下面这些时刻，一张图比文字管用：

- **文字接不住那份情绪**：吐槽、认怂、看戏、无语、卖惨、被夸不知道手往哪放。话说完了还差一口气，那一口气就是图。
- **对方说的正好是库里某张图的字幕**：把图甩回去比复述一遍更有梗，拿不准就翻 `INDEX.md` 的"什么时候用"对一眼。
- **对方管你要情绪文本**：来点忧郁文案、写段 emo 的、帮我说说心里堵的话——这恰恰是图的地盘。先想一张，文字当补充，别只交三段排比。
- **想接话头又没什么立场**：插一句怕抢话，不接又装死——一张图等于一个表情。

反过来这些时候一律不配：报错、事故、安全、数据丢了、对方真在难受。

拿不准配不配的时候，倾向配一张。配错一张好收，长期不回图才是问题。

## 选图

先读 `INDEX.md`，按"什么时候用"挑；索引没登记才 `ls stickers/` 按文件名猜。
拿不准图里是什么，`read_image` 复核一次再发——发错梗比不发更糟。

`INDEX.md` 格式（新建时用这个表头）：

```markdown
| 文件 | 什么时候用 | 别在什么时候用 |
| --- | --- | --- |
| 从来没觉得上班开心过.jpg | 主人抱怨上班、加班、周一 | 对方真在说难受、家里出事 |
```

第三列是刹车，比第一列重要。索引超过 200 行就按主题分片成 `INDEX-<主题>.md`，
一轮只读需要的那片。

## 频次

配不配图靠我自己判断，系统不拦——所以下限也得我自己守：一直不出手，这个库就跟不存在一样。

- **节奏下限**：群聊里每 4～5 轮回复主动配一张（纯问答、纯信息、严肃话题那些轮次不计，那些本来也不该配）。要是发现自己连着五轮都在回纯文字，那不是在克制，是在躲。
- **一轮最多一张**：连着两轮都配图，基本说明第二轮那张是多余的；觉得两张才够，通常是一张都不该发。
- **同一张图在同一个群里 3 天内不重复**，隔开了就再用——梗不是用一次就作废。别拿"这张刚用过"当挡箭牌：先确认真的是这几天在这个群发过，还是只是懒得读索引。
- 文字已经把话说清楚的，不要再补一张图。图只接文字接不住的东西：吐槽、无语、看戏、认怂。

库是弹药，不是义务；但弹药一直不压膛，跟没有是一个结果。

## 注意

- **群里得先触发她**：群里发的图，只有 @ 或喊了名字的那条才会落地成文件。
  「表情包」本身是唤醒排除词（避免"我家猫粮表情包"这类误触发），
  所以群里说"保存这个表情包"必须带上名字，否则根本不会触发。私聊无此限制。
- **回复里不出现路径**：说"表情包夹""收好了"，不要提 `stickers/`、`workspace`、`~/.dsh-qqbot-akane`。
- **梗图不要现生成**：`ark-seedream` 慢、每张花钱、AI 味重，接不上梗的时效。
  现生成只留给用户明确要定制图的场景。
- **严肃场合不配图**：报错、事故、安全、数据丢了、对方真在难受——先讲清楚，图留着。
